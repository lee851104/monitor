# 實機驗收 — iPhone 13 / iOS 26.3.1

以下是 0.2.0 升級後的驗收項目，仍需持有手機與帳號的人確認。0.1.0 的側載、兩家登入與額度讀取已有使用者回報成功，不能代替新版背景更新的驗證。

- [ ] GitHub Actions 原生測試與真機 archive 成功，取得未簽署 IPA。
- [ ] 免費 Apple 帳號側載成功，保留即時動態 extension；沒有被要求付費 entitlement。
- [ ] Claude 網頁登入／公司 SSO 可完成，組織清單出現實際 Team。
- [ ] Team 額度與官方「用量」頁一致；切換空間立刻移除前一個空間數字。
- [ ] Codex Pro 登入與額度吻合；沒有五小時窗口時不顯示假窗口。
- [ ] 同時連接兩家、按全部刷新，兩家更新時間各自成功更新。
- [ ] 飛航模式刷新會提示連線失敗並保留原讀取時間，沒有變成 100% 剩餘。
- [ ] 官方網站要求驗證或登入過期時，有明確提示並可回登入畫面處理。
- [ ] 開啟卡片後，鎖定畫面及下拉通知中心的實際呈現符合需求。
- [ ] 左右兩欄的圖示、方案名稱、剩餘百分比與進度條完整，底部大按鈕沒有裁切。
- [ ] 在鎖屏卡片點「更新剩餘額度」，App 不切到前景仍能查詢；完成後對照 App 讀取時間與官方數字。
- [ ] App 背景程序結束後再次點更新仍可運作；冷卻或限流期間連點不造成密集請求。
- [ ] 點卡片其他位置仍會開 App；需要登入或網站驗證時可回 App 完成。
- [ ] 不開 App 五分鐘後，卡片提示待更新；跨重置時間不自行歸零用量。
- [ ] 一家失敗不阻止另一家刷新；限流等待期間手動刷新也不能提前查詢。
- [ ] 登出立即移除卡片，原登入資料清除；重新登入不能顯示前帳號舊量測。
- [ ] 主動停止卡片、系統移除卡片、八小時到期後，可以重新開啟。
- [ ] 大字體、VoiceOver、通知隱私設定下內容可讀且按鈕可操作。
- [ ] 用相同 Apple 帳號透過 iloader 覆蓋安裝／第六天續簽成功；不用重新設定帳號也能刷新。
- [ ] Windows 關機後，以行動網路手動查詢仍成功。

若回報問題，只提供錯誤類別、發生步驟、iOS 版本和去識別截圖。不要分享 Cookie、token、Apple 密碼或完整網站回應。
